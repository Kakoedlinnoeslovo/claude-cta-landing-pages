# claude-cta-landing-pages

Copy source-of-truth for Recraft's CTA landing pages (https://www.recraft.ai/ and the paid-social landing pages it serves under /pm).

- `recraft/pm/copy.md` — https://recraft.ai/pm/ (vector/SVG paid LP)
- `recraft/pm-main-v1/copy.md` — https://www.recraft.ai/pm/main/v1 (generic paid LP)
- `recraft/home/copy.md` — https://www.recraft.ai/ (homepage, reference)

The `main` branch holds an unmodified baseline transcribed from the live pages. Proposed copy changes arrive as pull requests from `cta-scout/<slug>` branches, each tied to a specific running Meta ad creative. Pricing, offer terms, checkout and quiz content are out of scope for these PRs.

## Built pages
- `pm/index.html` — designed, self-contained build of https://recraft.ai/pm/ (open in a browser to preview).
- `pm/main/v1/index.html` — designed build of https://www.recraft.ai/pm/main/v1 (arrives via PR #2).
